From WhatsApp message to delivered PDF

A customer taps the WhatsApp button on your website. Here is what happens next.

Chat

The Sales agent answers questions and suggests products.

Order

It creates the order and shares your bank details.

Screenshot

The customer sends a payment screenshot.

Checks

Amount, receiver, transaction ID, date and signs of editing are checked.

Delivery

You reply APPROVE and the PDF is sent.

🛡️ Screenshots can be faked and the AI cannot see your bank account. So by default you confirm each delivery after checking your bank app. Automatic delivery can be switched on if you accept that risk.

Install in 10 minutes

  1. Install Python 3.10+. On Windows, tick Add Python to PATH.
  2. Download Dukaan AI and unzip it.
  3. Get a free AI key: Google Gemini (recommended), Groq or OpenRouter.
  4. Windows: double-click start_windows.bat, paste your key into the file that opens, save, and double-click again. Mac/Linux: run ./start_mac_linux.sh.
  5. The app opens at localhost:8000. Fill in ☰ → Store settings, then ask for your first product.
pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env      # add your free AI key
python run_app.py
